## Patru butoane, patru efecte

Orice val trigonometric se poate scrie așa:

> y = **A** · sin(**b**·x + **φ**) + **k**

| literă | ce face | cum se vede |
|---|---|---|
| **A** | amplitudinea | valul se înalță sau se turtește; dacă A e negativ, se întoarce cu susul în jos |
| **b** | frecvența | valul se strânge (b > 1) sau se lungește (b < 1); **perioada = 360° / b** |
| **φ** | unghiul de fază | valul alunecă la stânga sau la dreapta cu **φ / b** |
| **k** | mutarea pe verticală | tot valul urcă sau coboară; linia lui de mijloc devine y = k |

Pachetul numește b·x + φ **termenul dinamic** (cel care se schimbă cu x) și φ **termenul staționar**.

## Capcana lui φ

Când b nu este 1, valul **nu** se mută cu φ, ci cu φ/b. De ce? Valul ajunge în același loc acolo unde b·x + φ = 0, adică la x = −φ/b. În exemplul din pachet, y = 5·tan(⅘x + 20°) − 8, mutarea este −20° / ⅘ = **−25°**, adică 25° la stânga.

## Exemplul din pachet, verificat

Apasă **„Exemplul din lecție”** și vei vedea exact graficul din pachet:

- perioada lui tan este 180°, deci perioada nouă este 180° / ⅘ = **225°**;
- asimptotele (liniile verticale de care curba se apropie fără să le atingă) sunt acolo unde ⅘x + 20° = 90°, adică la x = 87,5°, și apoi din 225° în 225°;
- graficul taie axa y la 5·tan 20° − 8 ≈ **−6,18**;
- punctul în care tan = 1 se află la (31¼°, −3).

## Cum citești un grafic (metoda din pachet)

1. **Izolează** funcția trigonometrică: y + 8 = 5·tan(⅘x + 20°).
2. **Mută axele**: notează y′ = y + 8 și x′ = ⅘x + 20°. Acum ai graficul simplu y′ = 5·tan x′.
3. **Întinde**: pe orizontală totul se lungește de 5/4 ori (perioada devine 225°).
4. **Etichetează** puncte ușoare: intersecțiile cu axele, asimptotele și locurile în care tan = 1.

> Jocul „Potrivește valul” este metoda pe dos: vezi graficul și trebuie să găsești formula.
