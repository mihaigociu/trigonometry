---
title: Identity or impostor?
---

## What an identity is

An **equation** is true only for some values: sin x = ½ is true for x = 30° but not for x = 40°. An **identity** is true for **every** value: sin²x + cos²x = 1 has no exceptions.

## How to catch an impostor

**One counterexample** is enough. To show that sin 2x = 2 sin x is false, try x = 90°: the left side is sin 180° = 0 and the right side is 2·1 = 2. Done, it’s an impostor.

To show that an identity is true, examples are not enough, however many you try. You need a proof, like the one in the “sin(A + B), step by step” lab. The graphs help you **see** whether a proof is worth trying.

## Favourite impostors

| looks true… | …but | the truth |
|---|---|---|
| sin(x + B) = sin x + sin B | at x = B = 90°: 0 ≠ 2 | sin x cos B + cos x sin B |
| sin 2x = 2 sin x | at x = 90°: 0 ≠ 2 | 2 sin x cos x |
| sin(x/2) = (sin x)/2 | at x = 180°: 1 ≠ 0 | ±√((1 − cos x)/2) |
| sin(−x) = sin x | at x = 90°: −1 ≠ 1 | sin(−x) = −sin x (sine is *odd*) |

They all make the same mistake: they treat “sin” like a number you multiply by. But sin is a **function**: a machine that takes an angle and gives back a number.

## The packet’s families of identities

1. **Pythagoras**: sin²x + cos²x = 1, 1 + tan²x = sec²x, 1 + cot²x = csc²x
2. **Adding angles**: sin(A ± B), cos(A ± B)
3. **Double and half angles**
4. **Product to sum and sum to product**

> A memory trick from the packet: in sin(A + B) the sign stays “+”, and in cos(A + B) it flips to “−”.
